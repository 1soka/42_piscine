## 📖 About

This repository gathers my whole **42 Angoulême Piscine** journey: an intensive four-week selection bootcamp where you learn C and Unix from scratch, with no teachers, no lectures, only peer-learning, peer-evaluation and a strict coding norm.

Every exercise here was written by hand, checked by **Moulinette** (42's automated grader), reviewed by fellow pisciners and kept compliant with the **Norminette**. I passed the Piscine and was admitted to the 42 cursus. 🎉

## 📅 Days

| Day | Topic | Grade |
|:---:|:---|:---:|
| [**Shell00**](S00) | Unix basics: files, permissions, archives, `ls`, `find` and first steps with Git. | <img src="assets/grades/grade_50.svg" width="85" alt="50/100"> |
| [**Shell01**](S01) | Shell scripting with environment variables, pipes, `sed`/`tr` and base conversion. | <img src="assets/grades/grade_55.svg" width="85" alt="55/100"> |
| [**C00**](C00) | First C programs: `write`, characters, digits and printing combinations. | <img src="assets/grades/grade_50.svg" width="85" alt="50/100"> |
| [**C01**](C01) | Pointers: addresses, swapping values, division/modulo and integer arrays. | <img src="assets/grades/grade_100.svg" width="85" alt="100/100"> |
| [**C02**](C02) | String manipulation: copy, character checks, case conversion and capitalization. | <img src="assets/grades/grade_65.svg" width="85" alt="65/100"> |
| [**C03**](C03) | String comparison, concatenation and substring search (`strcmp`, `strcat`, `strstr`). | <img src="assets/grades/grade_50.svg" width="85" alt="50/100"> |
| [**C04**](C04) | Number ↔ string conversion: `putnbr`, `atoi` and custom bases. | <img src="assets/grades/grade_50.svg" width="85" alt="50/100"> |
| [**C05**](C05) | Recursion and math: factorial, power, Fibonacci, square root, primes and the ten queens. | <img src="assets/grades/grade_80.svg" width="85" alt="80/100"> |
| [**C06**](C06) | Command-line arguments with `argc` / `argv`: printing, reversing and sorting them. | <img src="assets/grades/grade_100.svg" width="85" alt="100/100"> |
| [**C07**](C07) | Dynamic memory with `malloc`: `strdup`, ranges, `strjoin`, base conversion and `split`. | <img src="assets/grades/grade_52.svg" width="85" alt="52/100"> |
| [**C08**](C08) | Header files, macros and structures. | <img src="assets/grades/grade_100.svg" width="85" alt="100/100"> |
| [**C09**](C09) | Building a static library (`libft.a`) and writing a Makefile. | <img src="assets/grades/grade_100.svg" width="85" alt="100/100"> |
| [**C11**](C11) | Function pointers: `foreach`, `map`, `count_if`, sort checks and `do-op`. | <img src="assets/grades/grade_50.svg" width="85" alt="50/100"> |
